# VEO v1 Errata

This file lists claims in the v1 documents, paper drafts, figures, web app and video that were wrong or overstated, and what replaces them. The pre-correction state is preserved at the git tag `v1-archive`. Where a v1 document disagrees with this file, this file is correct.

Source files for every number below are in [`journal_paper/results/`](../journal_paper/results/).

## Withdrawn

| v1 claim | Status | Why |
|---|---|---|
| Mean inverse-depth scale $s = 1.85 \pm 0.35$, and the per-scene scatter in Figure 2(a) | **Withdrawn** | Generated by `np.random.normal(1.85, 0.35, 244)` in the figure scripts, not measured. The figure scripts now plot measured scales from `alignment_ablation.json` when available, and otherwise only the sign counts. |
| Direct-fit scales in $[-0.72, -0.25]$ and inverse-fit scales in $[1.22, 2.85]$ (claims_and_evidence.md) | **Unverified** | No traceable source in the repository. |

## Corrected

| v1 claim | Corrected statement |
|---|---|
| VEO vs. humans: $\kappa = 0.4719$, 58.6% accuracy, vs. a 14.3% random baseline | Over all 50 regions: $\kappa = 0.259$ (rater 1) and $0.138$ (rater 2), accuracy 36% (18/50), macro-F1 0.262. The 0.4719 / 58.6% figures are for the 29 regions where VEO did not abstain (21/50 abstained); the majority-class baseline on that subset is 41.4%. No script in the repository computes the 29-region figure. |
| High precision on geometric classes (87.5% / 71.4% / 71.4%) | Correct as ratios, but the counts are tiny: textureless 7/8, thin_object 5/7, boundary_mixing 5/7. Reflection was 0/7. VEO never predicted occlusion or poor_lighting. |
| "Double-blind", "independent researchers", "randomly sampled" | Blinded (raters did not see VEO output); 2 raters; regions were taken at evenly spaced positions in the error-sorted list, then shuffled. |
| Inverse-depth alignment "guarantees" / "proves" $s > 0$ | Observed $s > 0$ in 244/244 scenes. This is the expected result of fitting disparity in disparity space (standard since MiDaS), not a guarantee or a contribution. |
| "Calibrated" ambiguity gate and scoring | All thresholds and scales are hand-set; nothing is calibrated against labels. |
| "Official held-out test split of 244 scenes and 1,449 frames" | Custom scene-disjoint split (seed 42, 70/15/15 over scene names) of the 1,449 labelled frames; the test split has 244 **images**. Not the official 654-image NYU test split. `configs/nyu.yaml` mislabels it `official_test`. |
| Evaluation mask removes Kinect dropouts | v1 uses NYU's in-painted `depths`, so dropouts are filled in, not removed. Errors there partly reflect in-painting. |
| Architectural "failure fingerprints" (ViT vs. Conv), "significantly" different | Exploratory label shares; no significance test; regions are relative (top 15% per image); models also differ in size, data and resolution. The reflection difference is not established (reflection precision 0/7). |
| Counterfactual "faithfulness" verified (0.646 → 0.000) | Scoring-function sanity check. The score is $1 - \text{var}/500$, so adding noise must lower it; the depth model was not re-run. Noise was uniform random integers, not Perlin noise, and features were re-extracted over the whole bounding box. |
| "Actionable downstream remediation", "+0.354%" | Oracle experiment: pixels were selected using ground-truth error, so it cannot run without ground truth. Effect: −0.35% regional AbsRel, −0.16% regional RMSE, global RMSE unchanged; no control, no significance test. Filter parameters were $d=5$, $\sigma_{\text{color}}=0.10$, $\sigma_{\text{space}}=3$ px (not 5 px). |
| Region AbsRel 0.2348 is "the mean over the 5,236 regions", 2.25× global | 0.2348 is the mean over the oracle boundary-mixing masks (207 scenes). Regions exceed their image's average error by construction. |
| Depth-discontinuity ablation (1.01%) shows occlusions are rare | The occlusion scale (1.0 m/px) is almost never reached, so that score is near zero (22/5,236 regions). Depth discontinuity is the feature most correlated with error ($r = 0.45$). |
| Brightness ablation changes 24.96% of labels | The brightness ablation also resets contrast, so it duplicates the contrast row. |
| Figure 3(a) region confidence "Medium" | High (the script selects only High-confidence regions; score 0.646 > 0.6). |
